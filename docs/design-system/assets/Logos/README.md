# Logos

`semed.png` é a marca oficial da SEMED de Itapuã do Oeste (pena, livro aberto e estrelas, tinta azul `#2b5598`). O PNG tem fundo cinza-claro `#f4f4f4`, não transparente: use sempre sobre `superficie` ou dentro de um quadro com `raio-lg`. Não recolorir, não recortar, não redesenhar. Tamanho mínimo 48 px.
