# Progresso

Barra de andamento com rótulo e contagem "4 de 6"; a porcentagem fica implícita na barra.

O consumidor fornece `valor`, `total` e `rotulo`. Preenchimento `semed` sobre trilho `superficie-2`, `raio-pilula`. Use para fichas validadas da turma e etapas da ficha. Nunca para resultado de aprendizagem: andamento não é desempenho.
